Platform Control

There's no backend by design — this panel shows the platform's current state and exactly how to make changes by editing js/data.js.

How admin actions work

Approve/Reject — add or omit the restaurant object in RESTAURANTS
Pin/Unpin — toggle pinned: true/false
Feature/Unfeature — toggle featured: true/false
Suspend — set status: "suspended"
Remove — delete the object entirely
Edit banners/offers — edit SITE_CONFIG

Every new restaurant registration arrives as a WhatsApp message — copy the RESTAURANT TEMPLATE comment at the top of js/data.js, fill it in, and commit.
